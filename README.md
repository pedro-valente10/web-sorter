# web-sorter

Limitações Atuais

Só funciona em navegadores Chromium (Chrome, Edge, Brave, Opera). Firefox e Safari não suportam o acesso a pastas.
Se o botão não responder ao abrir o arquivo direto do disco, sirva a pasta por localhost, que sempre funciona.
O MVP lê só a pasta escolhida, sem subpastas.
Formatos como HEIC ou RAW aparecem como um ícone com a extensão, em vez de miniatura.
